# paper-figure-guide

A house style for NeurIPS, ICML, ICLR, and CVPR figures.

- `GUIDELINE.md`: the rules
- `paperplot.py`: applies them (`import paperplot as pp`)
- `demos/`: one example per rule, made by `python3 make_demos.py`
- `poster/`: a conference poster template in the same style (pgfplots, Overleaf-ready) with presets for NeurIPS, ICLR, ICML, CVPR, ICCV, ECCV, AAAI, IJCAI, ACL-family venues, KDD and UAI, plus `svg2tikz.py` for vector logos. Rules, venue sizes and layout families: `GUIDELINE.md`, section 14

All demo data is invented. Do not cite it.
